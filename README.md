
# Sistema de Gestión de Pedidos de Comida Cusqueña

## Descripción
Proyecto académico desarrollado para el Laboratorio 1 del curso de Ingeniería de Software. Consiste en un prototipo web básico orientado al registro de pedidos de comida local en Cusco.

## Objetivo
Configurar un entorno de desarrollo y aplicar control de versiones utilizando Git y GitHub.

## Funcionalidades
- Visualización de platos típicos de Cusco.
- Registro básico de pedidos desde una interfaz web.
- Visualización de los pedidos registrados durante la sesión.

## Tecnologías utilizadas
- HTML, CSS y JavaScript.
- Visual Studio Code.
- Git.
- GitHub.

## Estructura del proyecto
- README.md: documentación principal del proyecto.
- index.html: interfaz web del prototipo.

## Ejecución
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo index.html en un navegador web.

## Estado del proyecto
Prototipo académico inicial. Los pedidos se muestran en la página, sin base de datos ni almacenamiento permanente.
